# AutoDestroy

> World of Warcraft **3.3.5a (WotLK)** addon · made by **feralpaw**

Mill, prospect and disenchant your bags with one button or keybind – one click per item.

## Features
- Milling, prospecting and disenchanting from a single button/keybind
- Only active on characters that actually have Inscription, Jewelcrafting or Enchanting
- Quality filter, soulbound filter, ignore list
- Auto-loot and auto-confirm of enchant confirmations (replace an existing enchant or bind an item; optional)

## Commands
| Command | What it does |
|---|---|
| `/ad` or `/autodestroy` | Show help / options |
| `/ad mill` · `/ad prospect` · `/ad de` | Switch mode |
| `/ad quality` | Set maximum item quality for disenchanting |
| `/ad soulbound` | Toggle disenchanting of soulbound items |
| `/ad accept` | Toggle auto-accepting enchant confirmations |
| `/ad ignore <item>` · `/ad list` · `/ad clear` | Manage ignore list |
| `/ad show` · `/ad hide` · `/ad toggle` | Show/hide the button |
| `/ad reset` | Reset settings |

## Installation
1. Download the latest ZIP from **Releases** (or *Code → Download ZIP*).
2. Copy `AutoDestroy` into `World of Warcraft/Interface/AddOns/`.
   The folder name must stay exactly like this (no `-main` suffix).
3. Restart the game or type `/reload`.
